# Анатомия машин

Интерактивный сайт-разрез: как устроены Toyota Fortuner 2.8D (дизель), BMW 530i (бензин) и Airbus A320.
Прокрутка ведёт камеру по корпусу, анимированные линии показывают путь топлива, воздуха, выхлопа, антифриза, масла, тока, гидравлики.

Запуск: откройте `index.html` в браузере или `python3 -m http.server` в корне репозитория.

- `js/core.js` — роутер, камера, главы, общие функции рисования
- `js/fortuner.js`, `js/bmw.js`, `js/a320.js` — чертежи и тексты каждой машины
- `js/insets.js` — анимированные схемы (цикл двигателя, турбина, АКПП, CFM56, блок-схемы)
